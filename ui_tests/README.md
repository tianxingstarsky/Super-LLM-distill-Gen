# 控制台交互回归

默认 CoT 要点的文本往返需保留用户指令核对的 final 阶段，不能因打开自定义编辑而扩大执行阶段。

使用 Streamlit 测试应用和受控数据验证页面路由、节点配置、语言、审核、预览与打包。执行 `python -m pytest ui_tests -q --tb=short`。

在核心 Python 回归结束后单独运行，避免共享本地服务端口冲突。测试中的样本是 fixture，产品页面必须读取真实状态。

维护断言时匹配真实组件键和应用端口，不恢复已经删除的预算按钮、工作区选择或重复模型页面。UI 样式变化仍需真实浏览器验收，测试通过不等于视觉验收通过。

`test_reasoning_checklist_controls.py` 覆盖新 CoT 默认生成中推敲、个人要点开关和旧任务模式的显式转换。模式转换只影响后续启动的草稿配置，保留用户保存的文本。
