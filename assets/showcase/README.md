These images explain ShuJian Cube on the public project page. They do not
contain workflow logic or measured quality claims.

- `hero-whale.png` is the main promotional illustration. Its references and
  fan-art notice are in `hero-whale-sources.md`.
- `quick-start.svg` is a compact product journey for the README.
- `download-windows.svg` and `watch-film.svg` are linked action labels.
- `deepseek-harness-plate.svg` identifies the preferred community integration.
  It places the unmodified DeepSeek favicon path on a project-made plate.
  The source is `website/public/favicon.svg` in official commit
  `f3803c96974ad4a94195fb97e5c637e9c2a3afe3`. The upstream MIT text is retained
  in `docs/licenses/deepseek-harness-MIT.txt`. Placement is not an endorsement.
- `workflow-map.svg` and `data-goals.svg` provide larger product overviews.
- Other PNG files and prompt records preserve earlier promotional assets.
