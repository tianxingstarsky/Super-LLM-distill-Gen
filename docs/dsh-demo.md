# dsh 演示记录与当前接入方式

当前接入请使用[独立适配包](../plugins/dsh-dataforge/README.md)。产品不再内置 Harness 子模块、SDK、启动器或补丁生成器。适配器自行声明版本、依赖、兼容范围和验证方式；核心只提供通用[控制协议 v1](external-control.md)。

独立包的验证包含：实际 SDK 的工具注册、依赖与优先级调度、任务归属、取消和子进程清理，以及真实 Harness 中的只读控制调用。付费模型生成与只读互通是两种不同验证，不由后者推断前者成功。

## 2026-09-10 历史记录

旧实现曾演示通过审核中心拉取两条记录、进行质量评审并提交判定。第一次因中心服务未运行而中断；第二次完成两条判定，并生成 250 条对话的草稿包。

当时质量报告记录 367 个问题，整体审核覆盖不足。草稿导出成功不等于数据可直接用于训练，也不是当前独立适配包的验收结果。

旧启动脚本、命令镜像及团队补丁生成器已移除。历史模型结果和文件保留作审计证据；不再提供已失效的复现命令。新的任务应遵循独立包的安装说明，先查询能力，再管理明确的工作流 run id。
