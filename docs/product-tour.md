# ShuJian Cube Product Tour

This guide describes the current screens. Each screen keeps the next step easy to find.

## Home

The home screen brings the main work into one place. It shows how to start, what is in progress, and which collections are ready for review.

## Create data

The creation workspace starts with three kinds of source: documents, assistant conversations, and a written brief. The source cards explain what each option accepts. Training goals can be selected one by one or from a suggested plan.

Before a run starts, a compact preview shows the stages for the selected goals. An expandable list explains how the stages share data. This makes the planned work visible before anything runs.

## Follow a task

The task center shows recent runs, their progress, and the latest updates. Open a run to see the stages that were used. Select a stage to read its status, quality notes, and recent events.

## Review examples

The review screen groups work by example type. Reviewers can read the source beside the generated answer, improve a selected example, and record a clear decision.

## Share a collection

The release screen lists completed collections and their files. Each published version shows its source, size, and available checks. Teams can inspect a file before sharing the full collection.

## Browse your library

The data library brings source files and finished collections together. A small summary shows what the workspace contains. Search and file groups help people find an item. The detail panel shows its location, size, and a content preview.

## Set up your workspace

Model connections, roles, and budget have their own page. Secret values stay hidden. A separate check shows whether a selected service can connect.

Workspace settings show the review points and generation preferences. Their current state stays visible beside a short explanation of when each one applies.
