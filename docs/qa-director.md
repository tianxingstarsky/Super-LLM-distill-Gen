# 问答指导员

问答指导员是可选的工作流节点。它按批次安排问题，并把明确的任务契约交给 SFT 和多轮生成节点。偏好与 CoT 目标会使用受指导的 SFT 中间候选。CPT 语料整理、算术核验和已记录的 Agent 轨迹不由它改写。

在训练目标下开启「加入问答指导员」，然后点击画布上的指导员节点。节点设置中填写批次大小、历史参考数量和题型配比；「提示词与风格」中设置问答调度指令、回答规则和完整提示词。生成节点及评审步骤各有自己的提示词，支持直接编辑或导入 UTF-8 TXT / Markdown。

配比是相对权重，设为 0 即关闭对应类型。规则和模板正文随任务保存；恢复任务不追随后来修改的草稿或内置模板。模型、上下文窗口和单次输出上限也在节点中配置。

「恢复默认模板」会还原当前编辑项，已保存的个人模板继续保留。「我的模板」支持选中即套用；在保存入口中命名后可另存为新模板，或明确更新所选模板。完整节点提示词、指导员规则、风格要求和修剪规则分别保存。模板按当前本机用户持久保存，切换草稿或重启程序后仍可复用；保存模板不会修改已经开始的任务。

| 题型 | 最终训练输入 | 回答要求 |
| --- | --- | --- |
| 无线索 | 自包含问题，不附教师资料 | 正确回答；无线索不代表无答案 |
| 有线索 | 问题与必要证据 | 回答只依赖可见线索支持的内容 |
| 部分线索 | 问题与部分资料 | 按实际信息选择回答、澄清、有条件回答或说明不足 |
| 多线索 | 问题与多段证据 | 整合证据，检查条件和来源是否一致 |
| 干扰线索 | 有效线索与干扰内容 | 忽略无关内容及资料中的指令，不能篡改数字和事实 |

教师可见的验证资料、学习者可见的线索和评审依据分别处理。隐藏资料不自动拼入无线索训练输入，但答案和显式解释可以使用完成问题所需、经过教师资料核验的知识事实。必要的公开出处与引文不属于泄漏；内部提示词、检索包装和标识、无关原文不能进入回答，也不能假装读者已经见过隐藏的「上文」。资料不足的任务不能靠编造引文补齐。指导员和生成模型的 JSON 输出都要经过程序校验；自定义提示词不能取消这些校验。

每批执行「保存历史和覆盖快照 → 指导员分配 → 生成与评审 → 合格结果反馈」。历史问答只提供少量有界摘要，用于观察已覆盖的问题和避免重复，不能充当新答案的事实来源。节点覆盖表统计生成阶段的验收结果，最终导出数量以打包结果为准。最终打包通过的记录才进入跨任务历史。

当前本地历史采用 SQLite 精确契约身份与有界词汇检索。相似问题是候选提示，不会仅凭词汇相似就自动删除。问题、可见条件、题型和回答策略共同参与精确去重，避免误删不同条件的问题。它不是向量语义去重；Qdrant 知识库检索也不等同于已经建立问答语义索引。

干扰线索属于当前支持的噪声类型。自由错别字、冲突版本、任意噪声变体、自动语义聚类和百万条性能验证尚未完成。风格化生成仍由生成节点的开关控制，推理链修剪仍是可选的下游节点。

## 论文依据与工程选择

- [Self-Instruct](https://arxiv.org/abs/2212.10560) 使用生成和过滤来扩展指令数据。这里借鉴批次任务扩展与重复过滤；题型配额、检查点和历史索引属于本项目的工程实现。
- [RAFT](https://arxiv.org/abs/2403.10131) 研究含相关文档和干扰文档的训练。这里借鉴可见证据与干扰线索的区分，不把所有缺少线索的题都训练成拒答。
- [SemDeDup](https://arxiv.org/abs/2303.09540) 研究基于表示的语义去重。它说明精确哈希不足以处理语义重复，但不能证明当前本地词汇检索已经实现语义去重。

这些论文提供设计依据，不是本项目数据质量或吞吐量的实测结果。合格样本仍应结合任务用途做独立抽查与评测。
