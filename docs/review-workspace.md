# 人工审核工作台使用说明

## 进入与导入

1. 使用现有启动器 `scripts/start_all.vbs`，打开 `http://127.0.0.1:8501/`，进入「人工审核」。控制台与审核 API 为同一服务进程，不需要另开审核服务。
2. 在控制台选择已经准备好的真实数据文件夹。注册工作区只记录位置，不搬动、覆盖源文件；失联目录不会被重建。
3. 首次导入由可信本机管理员点工作台右上角「导入样本」，选文件后明确点「将所选样本加入待审」。随后点「返回审核工作台」。日常浏览、编辑、判定不重新扫描源 JSONL。
4. 协作者使用「身份与接入」输入中心已发放的个人 API 密钥，点「验证并切换审核身份」。必须对当前数据集有权限；不能靠填写用户名冒充他人。工作台顶部显示当前身份。

浏览器会话身份与「配置自己主机上的审核 Agent」是两个独立配置。后者只验证并保存 gitignored 的远程接入文件，不创建账号、授予权限或自动启动 Agent。远程协作见 [collaboration.md](collaboration.md)。

**本机管理员入口不是多人网站登录系统。** 控制台仅监听本机回环地址，不应直接暴露到局域网或公网。远程接入使用既有受保护 API；见 [services-mode.md](services-mode.md)。

## 连续审核

- **左边选样本**：搜索 ID 或问题后回车；切换「待我审核」「我已审核」「全部记录」；使用分页查看全部队列。
- **中间读内容**：Markdown 默认渲染；用「定位消息」跳到长会话中部。阅读区独立滚动，完整展示消息、思考和工具内容。
- **右边做判定**：填写依据，或主动选择常用理由并调整。点「保留并下一条」或「驳回并下一条」才会提交；成功后进入下一条待审记录，理由清空。失败时保留理由。
- **暂时不判断**：点「跳过 / 下一条」，不生成审核票，也不等于驳回。

「待我审核」表示当前身份尚未判定，不代表其他人没审过。原版与修订版是独立记录，当前没有按版本家族折叠或多人任务独占领取。

## 局部修改

1. 点目标消息的「编辑」；正文和思考有各自入口。只有选中字段变成 Markdown 源码，其他消息仍保持渲染。
2. 修改后点「保存为新版本」，或在组件内按 Ctrl/Cmd+S。
3. 保存成功恢复渲染，保留阅读位置。新版本不会自动获批；核对新版后再提交判定。

取消编辑或切换样本时，有未保存内容会出现保护提示：继续编辑、保存当前文本修订后继续，或放弃未保存内容。「保存修订后继续」保存的是文本修订，不是审核理由或审核票。保存失败不会继续切换。

结构化多模态 content、角色与工具元数据只读，不会被文本框压成字符串。源文件、旧版本及旧审核票不被覆盖。过期内容会拒绝保存，不能用旧草稿静默替换其他人更新的内容。

草稿只在当前浏览器组件中保存，不是磁盘自动恢复。刷新/关闭页面依靠浏览器离开提示；不要把断网、崩溃或强制关闭后的恢复视为保证。

## AI 辅助修改

在目标字段点「AI 修改」，写清修改要求后「生成建议」。建议在原位展示，原文不变。可以「采用并保存新版本」「先手动调整」或「丢弃建议」。必须处理当前编辑/建议后才能判定。

调用仍受 G0 预算和 G1 数据外发授权限制，可能产生模型费用。页面不会替用户批准闸门。AI 修订只是建议，不等于正确答案或人工审核通过。

## 图片、审核票与快捷键

- 远程图片不会自动下载。本地图片只能在工作区允许范围内读取；不支持或被拒绝时明确提示未显示。未看见图片时，不能仅凭文字把样本认定为图文一致。
- 审核票绑定当前内容哈希与真实审核身份；已提交判定不能直接覆盖或删除。可以修订内容形成新版本，但这不是撤销旧票。
- Ctrl/Cmd+S：保存当前字段草稿。
- Alt+Enter：保留；Alt+Backspace：驳回；Alt+右箭头：跳过。快捷判定仅在组件内生效，输入文字或操作下拉框时禁用，理由仍必填。

本次改动是内置审核工作台，不是 dsh 原生 UI。浏览器实测、自动化结果与未覆盖范围见 [review-workspace-acceptance.md](review-workspace-acceptance.md)。
