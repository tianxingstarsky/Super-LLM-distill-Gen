# 生成中来源查证

目标是让作者在交付答案前有机会核对具体来源。已有评审检索发生在稿件完成后，不能替代这条生成路径。新路径只在 CoT 的协议 7 中显式启用，既有冻结任务和默认配置不变。

## 接口与范围

在工作流创建接口的 `node_generation.cot` 中配置：

```json
{"source_lookup":{"version":1,"max_rounds":2,"max_hits":3}}
```

同一节点需要 `enabled=true` 和版本 7 的 `self_check`。目前是运行接口能力，尚未新增页面开关，也未将它设为默认。节点已有提示词、自定义思考要点和语言配置继续通过原请求投影传入。

新建的默认思考要点同时加强真实 user 指令遵循：以当前请求和有效的历史用户约束确定任务；分清用户要求、待核验前提及待分析引文；最终答案对照用户实际要求检查范围、语言、格式、篇幅和子请求。它不强制输出任务分析或检查表，也不为迎合错误前提改写事实。final 专用规则仅在最终答案阶段加入，自定义与冻结规则不被升级器覆盖。

`GenerateWithSources` 调用作者模型，按需执行 `search_evidence` 或 `read_evidence`，然后将原始助手消息和真实工具返回追加到同一会话。完整 `reasoning_content`、工具 ID 和供应商状态不被替换为用户文本。联合生成或原生前缀的推理阶段可使用该能力；原生前缀回答阶段继续消费完整已生成前缀，不复制工具历史到不支持它的 beta 前缀接口。

查询使用当前任务已认证资料的 SQLite FTS5/BM25 索引。返回的是原文精确字符范围、哈希、已知页码和行号。未知页码保持空，不猜页码。选定资料行范围先经过原认证和投影，检索不得越界。对话历史继续作为任务约束，但不会被索引为独立事实。阅读任务的教师知识与用户可见文章仍依原有角色协议区分。

默认示例最多两轮查证和一轮完成；每轮可并列执行最多四个工具。相同查询不重复检索；一整轮重复且无进展则停止并保留记录。最后一回合仍携带工具定义以保留思考上下文，但关闭新工具调用。每个实际模型回合保留原检查点、模型并发与取消机制。

当前模型工具接口使用完整回执传输，日志明确标记 `complete_response`，不伪造逐 token 时间。此版本仍保留原始完整资料前缀，检索用于局部定位，不宣称已减少首次输入 token。

## 交付与效果边界

完整工具对话在候选的 `generation_sources` 中留存，既有训练投影只输出原有训练字段。查证收据不写 `passed`，明确 `semantic_status=not_assessed`。模型可不查证直接作答；这种能力并不保证它选择了正确证据，也不能保证它改对单位或逻辑。已有结构、语言表面和推理合同校验仍然执行，不因命中而放行。

这是本地原文检索路径，不是向模型注入向量，也不宣称接入了在线 Qdrant 或纠错经验库。可控工具调用会增加回合，真实成本与可用率需另做同题实验。此轮只验证离线合同和实际资料检索，不调用付费模型，先前 4/10 的可用率仍是最近一次真实质量结果。

## 依据与验证

- [DeepSeek 思考模式](https://api-docs.deepseek.com/guides/thinking_mode/)：携带 tools 时须完整回传历史 reasoning_content；普通无工具请求不能被误称为同等推理续接。
- [SQLite FTS5](https://www.sqlite.org/fts5.html)：成熟的本地全文检索及 BM25 排序实现。
- [Corrective RAG](https://arxiv.org/abs/2401.15884)：检索本身可能失败，证据相关性不能被默认为正确。此实现并非该论文完整复现，也未增加其独立检索评估器或联网搜索。

回归：`tests/test_generation_source_lookup.py`、`tests/test_integrated_reflection.py`、模型工具协议、原生前缀、资料角色、工作流节点和 DDD/洋葱架构测试。

2026-10-26 验证记录：工具协议、原生前缀、资料角色及相关回归 255 项通过（一次既有 Pydantic 测试警告）；最终业务/架构组合 109 项通过，来源查证补测 14 项通过，节点设置 6 项通过。这些是存在交集的分组，不能相加当作独立测试总数。真实论文的手工查询检索结果保存在本机 `generation-source-lookup-offline/retrieval.json`；引文逐字核对原文，包含未命中派生总数等局限。没有新增付费模型调用，也未重新测量 10 条样本的语义可用率。
