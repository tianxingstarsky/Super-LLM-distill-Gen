# 知识问答与资料问答穿插生成

## 操作入口

在工作流中点击“对话指导员”，进入“节点设置”，将“生成内容”设为“知识为主，穿插资料”。新建草稿默认资料问答触发概率为 20%，其余约 80% 为知识问答。滑块允许 0–100%；也可以直接选择只生成其中一种。

比例表示每道新题的触发机会，不是批次配额。小批次不保证两类都出现；资料耗尽时不通过重复、编造或补齐数量凑比例。选择路线不请求模型。

画布展示“指导员 → 知识问答／资料问答 → 原有 SFT、多轮节点”。路线按钮直接打开指导员配置；两条路线共用已有模型和生成节点，不增加执行阶段、并发任务或虚假的完成状态。运行任务展示冻结配方，不能通过点击路线热改概率。

## 两种输入边界

- 知识问答：教师知识用于生成和核验，训练用户消息不附原文。
- 资料问答：必要阅读内容实际放进用户消息并保留在训练对话中。回答模型只接收该可见选区；不额外投放完整教师文档、私有证据引文或私有规划指导。源文件和完整规划仍保留为审核、溯源记录。
- 没有真实可读内容时，记录退回知识问答的原因，不伪造资料，也不为选择路线额外调用检索或模型。

这是上下文与训练用途的分流，不是质量保证。原有事实、角色、去重与格式检查继续执行；未评审的结果不能标成评审通过。本次没有把独立的 CoT 局部编辑实验接成默认生产步骤。

## 合同与维护归属

新配方显式保存 `qa_director.learning_goal_mix={version:1, document_reading_probability:0.2}`，并以运行 ID 冻结 `qa_learning_goal_mix_seed`。纯领域规则 `qa_learning_goal_routing.py` 根据种子与候选 ID 做确定性哈希选择；重试次数、传输重连和返工轮数不参与抽取。

指导员请求前，程序为每题固定具体用途和允许题型。路线收据随后进入候选合同，消费者只接受与冻结配方匹配的程序收据。生成消息、资料投影、知识表述与审核使用逐题用途，不能再让运行级的 `mixed` 覆盖它。

阅读范围认证复用原有规划边界、父版本认证和真实用户消息；不额外猜测分行、删除干扰内容或要求包装文字逐字属于教师全文。原生及旧式生成请求、重答和可用资料工具采用同一个范围投影，避免某一条模型适配路径重新带入全文。

固定问题重答复用父题目、用途、概率策略与种子，不重新规划或抽签。合并返工要求父任务拥有兼容的冻结策略；不兼容时提示拆分，发模型请求前结束。新版路由任务与旧任务也须分开返工。

没有新版策略字段的旧配方保持原行为，既有任务、缓存与导出不迁移。复用旧草稿时不会默默启用新版采样；用户选择混合生成或调整概率后才启用。导入完整会话与已有人工题目不强行套用自动抽取。

维护入口：

- `workflows/domain/qa_learning_goal_routing.py`：策略、逐题选择、收据和可见范围。
- 既有指导员运行时与工作流应用：资料可用性、请求前固定用途、父配方复用。
- `workflow_director_settings.py`、`workflow_reuse.py`：节点配置、草稿保存与复用。
- `workflow_canvas.py`、`workflow_canvas_frontend/`：配置路线的可视化，不承担调度。
