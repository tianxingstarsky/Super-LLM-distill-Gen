# CPT 文档清洗与来源审查

文档 CPT 是保留有用的来源语料，不是把文档改成问答，也不为达到期望数量扩写知识。新建任务可以在文档节点配置模型解析，再在 CPT 节点配置清洗模型、独立审查模型和对应提示词。确定性检查、批内去重、已发布语料参照查重和评测集去污染仍继续执行。

## 保真清洗

`cpt_processing` 为 `{"mode":"model","review_mode":"text"}` 时，每个真实来源片段独立清洗，再独立审查。清洗只允许删除可确认的排版噪声、整理断行和阅读顺序，必须保留实质段落、条件、否定、数字、单位、引用、表格关系、代码和数学公式。数学公式使用 LaTeX 表达，不能改变数学含义或用概述替代全文。

清洗器须返回完整正文、明确的不确定标记和删除噪声类型。损坏或无法确认的内容不能凭常识补全；不确定结果隔离，不生成额外语料补足数量。独立审查除五维质量评分外，必须分别确认来源保真、数字与单位保留、公式与代码保留、当前分块实质内容覆盖。任意一项不通过，即使整体评分较高，也不导出。

模型辅助解析的来源片段还提供解析前原文、完整解析结果及其摘要给审查器。审查先核对整个来源段到完整解析结果的实质内容覆盖与保真，再核对当前分块到清洗结果；任一层不通过都隔离。原文页面或解析前段落可能包含多个分块，其他分块须在完整解析结果中保留，不必重复写入当前清洗块。此检查仍以传入的来源段为依据，不能证明整份文档在前置提取时没有遗漏。

## 视觉核对

`review_mode:"vision"` 在有原页时让独立审查模型同时查看固定来源的页面图片。节点所选审查模型必须有与当前服务一致的视觉能力确认；不能根据模型名称猜测能力。每次只传入当前原页，不将整份 PDF 一次塞入上下文。来源快照及图片内容固定于当前运行。

混合来源中的 Markdown、TXT、TeX 和 DOCX 纯文字块使用文本原文核对，逐条记录实际 `review_mode:"text"` 与请求的 `requested_review_mode:"vision"`。PDF、独立图片和 DOCX 图片块需要原页图片；图片无法定位时隔离为 `cpt_visual_source_unavailable`，不会静默降级成文本审查。

视觉模型判断仍有误差。多模态审查用于发现转录、数字、表格和公式问题，不是对事实真实性或整份来源许可的保证。

## 可控配置与恢复

CPT 节点的 `workflow.cpt_clean` 和 `workflow.cpt_review` 提示词可编辑、恢复默认并使用个人提示词库。模型、上下文窗口、输出上限、模板正文和清洗配置随任务保存。成功清洗与审查分别保存检查点；审查发生格式或服务错误时，恢复继续复用已成功清洗，不重新调用清洗模型。

选择 `{"mode":"native"}` 保留确定性检查路径，模型清洗和审查不产生调用。缺少 `cpt_processing` 的旧 API 任务和历史配方也继续使用原路径。新增处理配置使用配方 v14；v9–v13 的节点模板目录保留原样，恢复旧任务不会插入新的模型步骤。

## 研究依据与边界

[Nougat: Neural Optical Understanding for Academic Documents](https://arxiv.org/abs/2308.13418) 讨论 PDF 在数学表达等内容上丢失语义，以及将文档视觉内容转录成标记语言的方法。这里借鉴其文档与公式保真的问题定义，未接入 Nougat 权重，也不声称通用多模态模型能达到其论文结果。具体清洗合同、独立审查和检查点是本项目的工程实现，需要用实际领域 PDF、表格、公式和代码进行验收。
