# 训练验证规则

`validation.py` 定义实验配置、确定性摘要、题目划分和完整监督合同。
`complete_reasoned_generation` 定义本次开启思考的验证输出何时完整；`assessment_usability` 从评分、已确认矛盾与完整输出推导报告指标。未知保持未知，不由外部 JSON 的自报通过字段决定。
每个训练分支只遍历其训练单元一次；CPT→SFT 为先 CPT 后 SFT 的联合有序一轮。
不读取文件、模型、CUDA 或训练框架，不根据训练 loss 推断任务正确率。

`grpo.py` 定义可选 GRPO 验证的不可变配置、确定性且题目隔离的精确数值任务。
训练轮次最多一轮，每组仅更新一次；答案单独存档，不作为生成输入。
模型答案解析和奖励由基础设施的 TRL／Math-Verify 承担，不维护第二套响应语法。
默认生成容量为 32768 tokens；`validate_capacity_resume` 只允许改变输出位置、父任务引用和
增加输出容量，其余训练配置与题目配置必须和父任务一致。基础设施恢复原检查点进度，
不能把剩余训练当作新一轮。`tests/test_grpo_domain.py` 检查预算、续训约束、任务隔离和标准数值。
