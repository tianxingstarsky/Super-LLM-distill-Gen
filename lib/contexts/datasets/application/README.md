# 数据集用例

`service.py` 面向页面提供预览、分布统计、文件和发布操作；`ports.py` 是它消费的存储端口；`trainer_export.py` 协调训练格式转换。

用例不启动生成，不直接打开 ZIP、SQLite 或模型服务。跨域读取业务含义通过公开合同，具体版本和文件的读取通过注入端口。

`asset_catalog.py` / `asset_catalog_ports.py` 提供资料与交付目录和高级运行记录目录。默认目录在存储遍历前排除中间记录，仍保留数量上限、文件版本核验及直接下载限制。旧模块只转发，历史文件与任务格式不变。组合根为 `bootstrap/asset_catalog.py`；回归见 `test_asset_catalog.py`。

预览数量限制在用例入口落实，适配器仍需核验源版本。增加导出类型时先修改领域格式规则，再接转换与发布，不能仅增加一个下载按钮。
