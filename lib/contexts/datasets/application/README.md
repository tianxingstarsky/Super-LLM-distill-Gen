# 数据集用例

`service.py` 面向页面提供预览、分布统计、文件和发布操作；`ports.py` 是它消费的存储端口；`trainer_export.py` 协调训练格式转换。

用例不启动生成，不直接打开 ZIP、SQLite 或模型服务。跨域读取业务含义通过公开合同，具体版本和文件的读取通过注入端口。

`asset_catalog.py` / `asset_catalog_ports.py` 提供资料与交付目录和高级运行记录目录。默认目录在存储遍历前排除中间记录，仍保留数量上限、文件版本核验及直接下载限制。旧模块只转发，历史文件与任务格式不变。组合根为 `bootstrap/asset_catalog.py`；回归见 `test_asset_catalog.py`。

预览数量限制在用例入口落实，适配器仍需核验源版本。增加导出类型时先修改领域格式规则，再接转换与发布，不能仅增加一个下载按钮。

`training_loader.py` 的 `iter_training_examples` 惰性消费单份规范记录，经现有
`to_trl_sft` 每条校验和规范化一次，再为每个助手轮生成独立监督视图，保留目标轮的
`thinking` 推理。显式非 eligible 记录拒绝加载；没有训练控制时仅允许调用方明确
指定 `default_effort` 形成只读视图，不猜测教师 effort 或旧解释深度的对应关系。
`TrainingTurnEncoder` 接收截至目标轮的消息深拷贝、已验证的 effort 和完整工具定义；
具体模型编码由注入实现负责，不支持的工具必须明确拒绝。来源记录与消息索引仅放在
返回例的 metadata，不进入模型输入。用例不写数据集、不改变现有 TRL 导出或任务缓存。
验证覆盖惰性消费、每个助手轮的推理监督、输入不变、控制缺失与冲突，以及 DDD 边界。

成对标记由普通导出采用；训练加载器仅复用 TRL 的字段规范化，不预先标记，让编码器的显式
关闭或目标替换设置仍能生效。每个目标助手轮优先传递消息自身的冻结控制文字配置，缺省才
取记录配置，防止多个节点的规则混用；已有的源记录和全部推理不改写。
